# Changelog

All notable changes to this project will be documented in this file.

## [0.1.0] - 2026-11-22

### Added

- Multi-user Immich → Pixel FTP sync (webhook + catch-up cron)
- FastAPI health/ready/status APIs and Immich AssetCreate webhook handler
- Web portal for YAML config, live status, FTP test, and catch-up trigger
- Docker image/compose with blank-volume config seed
- SQLite sync state, tests, and Immich AssetV1 payload parsing
